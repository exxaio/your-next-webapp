# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within **your-next-webapp**, please do **NOT** open a public issue on GitHub. Instead, report it privately to the maintainers:

- Open a private security advisory on GitHub under the **Security** tab of the repository, or
- Contact the project maintainers directly via repository channels.

Please include the following information in your report:
- Type of issue (e.g. buffer overflow, SQL injection, cross-site scripting, authentication bypass)
- Detailed step-by-step instructions to reproduce the issue
- Affected components and environments
- Any proposed remediation or patches

We will acknowledge receipt within 48 hours and work with you on an coordinated disclosure schedule.
